# Multi-Layer Layout System

## Purpose
A 3×3 collage is a nine-tile editorial composition. Each tile may contain several designed layers; it is not required to be a single untouched photograph. The nine tiles should feel related without forcing every boundary to connect literally.

## Tile model
Plan each tile as a stack, using only the layers that improve the composition:
1. Background: warm white, off-white, pale neutral, or a restrained solid color.
2. Primary photograph: the strongest documentary image in the tile.
3. Secondary photograph or detail: optional; use as a crop, inset, strip, or small framed fragment.
4. Illustration: optional scene-relevant subject or symbolic motif.
5. Line art: botanical, topographic, architectural, textile, or other light outline work.
6. Typography: accurate text added as real editable type, never generated as raster lettering when correctness matters.
7. Color-extension layer: restrained blocks, strokes, or shapes that repeat the palette.
8. Cross-grid layer: selected lines, motifs, or colors that echo across neighboring tiles.

Do not force all eight layers into every tile. Use hierarchy and negative space.

## Grid roles
- Center: strongest anchor, title, or most iconic photograph; avoid making it needlessly crowded.
- Corners: establish the overall tone and frame the composition.
- Edge tiles: may carry typography, line art, or elements that visually point inward.
- Middle-edge tiles: useful for bridges between photographs and graphic elements.
- Diagonals: can create a secondary path through the whole grid.

## Composition rules
- Establish one dominant visual anchor per tile.
- Vary density: pair dense photo tiles with quieter graphic tiles.
- Keep the background family consistent across all nine tiles.
- Preserve enough photographic area that the travel story remains authentic.
- Use a shared baseline, margins, or typographic grid to make the collage feel designed.
- A tile may connect by contrast or visual echo; literal continuation is not mandatory.

## Deliverables
Before rendering, provide a tile plan with each cell's role, photo candidate, layer stack, palette, text, and links to adjacent cells. Then render a low-resolution proof and review the full grid at phone-screen size.
