# Typography Layer

## Text accuracy
All meaningful text must be added as editable text using a known font and verified wording. Do not rely on an image model to render Chinese, Tibetan, English, place names, or dates correctly.

## Hierarchy
Use one primary title, optional short secondary text, and tiny supporting labels only when needed. Keep the type system limited to one or two font families and a small number of weights.

## Placement
- Place text on clear background or deliberately quiet image areas.
- Keep contrast strong enough for phone viewing.
- Align text to a consistent grid or margin system.
- Avoid covering a photograph's key subject or documentary sign.
- Check that typography does not become a ninth-tile-only afterthought; it should balance the whole composition.

## Tibetan text and cultural review
Use exact user-approved wording and verified glyph support. If using Tibetan script, verify the font supports the script and check shaping/rendering in the actual design software. Ask for review if the wording has religious or cultural significance. Do not invent translations or treat decorative pseudo-script as real language.

## Final proof
Check spelling, punctuation, glyph rendering, line breaks, font fallback, and readability at the final display size.
