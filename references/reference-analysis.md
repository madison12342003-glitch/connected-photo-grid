# Reference Image Analysis Protocol

## Goal
Translate a visual reference into reusable design rules without copying it blindly.

## Analyze
Record:
- overall grid and tile spacing
- background color and texture
- per-tile photo count
- photo-to-graphic ratio
- illustration style
- line-art style and line weight
- typography hierarchy and placement
- palette and accent distribution
- recurring motifs
- literal cross-grid continuities
- visual echoes between non-adjacent tiles
- negative-space rhythm
- overall density and viewing distance

## Separate rules from content
Rules worth transferring may include layered tile construction, restrained palette, repeated motifs, varied density, typography rhythm, and full-grid coherence. Content specific to the reference (such as a particular deity, flower, or landscape) should not be copied unless relevant and appropriate to the new project.

## Output format
Produce:
1. a short style summary
2. a nine-tile role map
3. a palette
4. a layer stack for each tile
5. recurring motifs and where they appear
6. cross-grid paths and echoes
7. typography notes
8. risks and items requiring manual review
